## Эксперимент 2
При K=10 N=1'600'000
При K=30 N=666'666

Можно сделать вывод, что зависимость K от N нелинейная.

Потому что, чем больше K, тем дольше откладывается запуск последнего процесса, что может привести к тому, что когда запустится последний, первый уже может убиться.
